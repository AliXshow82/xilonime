Xilonimeh Alpha 0.36

- Rebuilt with Tauri: about a 3.5 MB installer, faster start and much lower memory use.
- Automatic signed updates: future versions appear in the title bar and install with one click.
- Completely new design: sidebar with status filters and counts, a Continue watching row and poster cards.
- The app starts in English. Your list from the previous version is moved over on first launch.
- Better phone layout for the web app.

Upgrading from 0.32 or older: install this version once by hand, then uninstall the old Electron version from Windows Settings. From now on updates install themselves.
